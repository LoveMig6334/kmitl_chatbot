**06026251 บัญชีการเงิน**
FINANCIAL ACCOUNTING
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : None

แนะนำการบัญชี วิธีการทางบัญชีและธุรกรรม ภาพรวมวงจรบัญชี (บันทึกรายวัน บัญชีแยกประเภท ปรับปรุงรายการบัญชี และปิดบัญชี) ต้นทุนสินค้า การบัญชีสำหรับธุรกิจซื้อขาย สินค้า การบัญชีสินทรัพย์ การบัญชีหนี้สิน การบัญชีส่วนของเจ้าของ การจัดทำงบการเงิน งบกำไร ขาดทุนและงบดุล การวิเคราะห์ทางการเงิน การวิเคราะห์แนวตั้ง การวิเคราะห์แนวนอน และการ วิเคราะห์อัตราส่วน

An introduction to accounting, accounting methods and transactions, accounting cycle overview: journals, ledgers, adjusting, and closing entries, inventory cost, merchandising businesses, asset, liability, shareholder equity, financial statement: income statement, balance sheet, and cash flow, financial analysis, vertical analysis, horizontal analysis, and ratio analysis.

**06026252 การวิเคราะห์ด้านการเงิน**
FINANCIAL ANALYTICS
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : None

แนะนำและภาพรวมของการวิเคราะห์ทางการเงิน การประยุกต์การวิเคราะห์ทาง การเงินในสถานการจริง เทคนิควิเคราะห์ข้อมูลอนุกรมเวลา การวัดประสิทธิภาพการพยากรณ์ การ พัฒนาโมเดลพยากรณ์ ARIMA ประเมินความสมดุลของเสี่ยงและผลตอบแทนในทฤษฎีพอร์ตโฟลิโอ สมัยใหม่ ราคา ผลตอบแทน และความเสี่ยงของหุ้น เทคนิคการวิเคราะห์ในบริบทอื่นๆ แนะนำ อัลกอริทึมการเทรดหลักทรัพย์

Introduction and overview of financial analytics, apply financial analytics in real-world situations, techniques to analyze time series data, forecasting performance measures, building an ARIMA forecasting model using R, evaluate the risk- reward trade-off in modern portfolio theory, prices, returns, and risk of corporate stocks, analytical techniques in other domains, introduction to algorithmic trading
