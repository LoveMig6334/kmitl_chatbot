**06026222 คอมพิวเตอร์วิชัน**
COMPUTER VISION
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : None
เทคนิคพื้นฐานในการประมวลผลภาพและวิดีทัศน์ ความเข้มแสงและสี การแปลงภาพ การคอนโวลูชันภาพ รูปทรงและเส้นแสดงรูปร่าง ฮิสโตแกรม การแบ่งส่วนภาพ การสกัดวัตถุ การตรวจจับและจับคู่คุณลักษณะเด่น การลบฉากหลัง การเฝ้าติดตาม การรู้จำวัตถุ วิชัน 3 มิติ การเรียนรู้ของเครื่องในคอมพิวเตอร์วิชัน การประยุกต์ใช้ เช่น ระบบตรวจสอบสินค้า การวิเคราะห์ภาพทางการแพทย์ การยืนยันตัวตนโดยใช้ซีวมิติ พาหนะอัจฉริยะ และระบบรักษาความปลอดภัย

Basic image and video processing, intensity and color, image transformation, image convolution, shape and contour, histogram, image segmentation, foreground extraction, feature detection and matching, background subtraction, tracking, object recognition, 3D vision, machine learning in computer vision, some applications such as product inspection system, biomedical image analysis, biometric authentication, intelligent vehicle, and security system.

Fundamentals of image processing, Intensity transformations and spatial filtering, Frequency domain processing, Image restoration, Morphological image processing, Image segmentation.
