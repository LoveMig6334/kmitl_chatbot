06026217 การเรียนรู้ของเครื่อง
MACHINE LEARNING
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : None
ความรู้พื้นฐานของการเรียนรู้ของเครื่อง การเรียนรู้แบบมีผู้สอน การถดถอยเชิงเส้น วิธีกำลังสองน้อยที่สุด การถดถอยโลจิสติก อัลกอริทึมเพื่อนบ้านที่ใกล้ที่สุด โครงข่ายประสาทเทียม ซัพพอร์ทเวเกเตอร์แมชชีน การเรียนรู้แบบไม่มีผู้สอน การจัดกลุ่มแบบเคมีน อัลกอริทึมการหาค่า ความคาดหวังสูงสุด การลดมิติข้อมูล การวิเคราะห์องค์ประกอบหลัก การตรวจสอบไขว้ การประเมินประสิทธิภาพของแบบจำลอง การประยุกต์ใช้ของการเรียนรู้ของเครื่อง

Basic of machine learning, supervised learning, linear regression, least squares, logistic regression, k-nearest neighbour, neural network, support vector machine, unsupervised learning, k-mean clustering, expectation-maximization algorithm, dimensionality reduction, principal component analysis, cross-validation, evaluating model performance, machine learning applications.

DEEP LEARNING

Essential mathematics for deep learning, vector calculus, matrix decomposition, understanding the concepts in probability, neural network, feed-forward neural network, multiplayer-perception neural network, loss function, convolution neural network, recurrent neural network

06026219 การประมวลผลภาษาธรรมชาติ
NATURAL LANGUAGE PROCESSING
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : None
ภาพรวมโมดูลการประมวลผลภาษาธรรมชาติ งานด้านการแบ่งกลุ่มข้อความ เช่น การจัดกลุ่มข่าว การจำแนกอารมณ์ การกรองสแปม ตัวแบ่งกลุ่มแบบดั้งเดิม เทคนิคการเรียนรู้เชิงลึก แบบจำลองภาษาและการกำกับข้อความที่มีลำดับ การแทนข้อความในแบบจำลองเวคเตอร์ งานด้าน การสร้างแบบบรูปของงานที่มีลำดับ เช่น การแปลภาษาด้วยเครื่อง การย่อความ การตอบคำถาม

วท.บ (วิทยาการข้อมูลและการวิเคราะห์เชิงธุรกิจ) สาขาวิชาวิทยาการข้อมูลและการวิเคราะห์เชิงธุรกิจ คณะเทคโนโลยีสารสนเทศ สจล.
