06026208 พื้นฐานวิทยาการข้อมูล
FUNDAMENTALS OF DATA SCIENCE
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : None
วิทยาการข้อมูลกับแรงจูงใจเชิงธุรกิจ นิยามของวิทยาการข้อมูล กระบวนการทำ วิทยาการข้อมูล เช่น กระบวนการ คิดสติเอม การทำความเข้าใจข้อมูล การเตรียมข้อมูล ดึงข้อมูล จากเว็บไซต์ การดึงข้อมูลจากเอพีไอ นิยามของปัญญาประดิษฐ์ การแทนความรู้ การใช้เหตุผลแบบ ตรรกศาสตร์และความน่าจะเป็น คอมพิวเตอร์วิทัศน์ การประมวลผลภาษาธรรมชาติ การเรียนรู้ของ เครื่องจักร ภาษาไพธอนสำหรับวิทยาการข้อมูล
Data science motivation for business, Definition of Data Science, Data Science Lifecycle: CRSDM, Data Understanding, Data Preparation, Web Scraping, API Request ,Definition of Artificial Intelligence, Major subfields of AI: Knowledge Representation, Logical and Probabilistic reasoning, Computer Vision, Natural Language Processing, Machine Learning, Python Programming for Data Science.

06026209 การแสดงข้อมูลด้วยแผนภาพ
3(2-2-5)
DATA VISUALIZATION
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : None
หลักการการแสดงข้อมูลด้วยแผนภาพ การออกแบบการแสดงข้อมูลด้วยแผนภาพ เครื่องมือที่ใช้ การแสดงข้อมูลด้วยแผนภาพ การได้มาซึ่งข้อมูล การจัดระเบียบข้อมูล การเลือก แผนภูมิต่าง ๆ ที่เหมาะสม เช่น ฮีทโทรแกรม แผนภูมิการกระจาย แผนภูมิเส้น แผนภูมิแท่ง แผนภูมิ วงกลม แผนภูมิต้นไม้ แผนภูมิแบบเครือข่าย กราฟสตรีม แผนภูมิตัวชี้วัดผลงาน แผนที่ แผนภูมิแบบ ปฏิสัมพันธ์ การอธิบายแผนภูมิ หลักการเล่าเรื่องด้วยภาพ
Principles of data visualization, data visualization design, data visualization tools, data acquisition, data organization, choosing the appropriate chart type, e.g., histogram, scatter plot, line chart, bar chart, pie chart, tree diagram, network chart, stream graph, KPI Chart, map, interaction chart, chart description, Storytelling with data.

06026210 การหาค่าเหมาะที่สุด
3(3-0-6)
OPTIMIZATION
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : None
การสร้างตัวแบบกำหนดการเชิงเส้น วิธีแก้ปัญหากำหนดการเชิงเส้น ปัญหาควบคู่ ในกำหนดการเชิงเส้น กำหนดการเชิงเส้นและตัวแบบถดถอยควอนไทล์ การหาค่าเหมาะที่สุดกับ ปัญหากำลังสอง การหาค่าเหมาะสมที่สุดกับปัญหาคอน วิธีเกรเดียนต์เพื่อแก้ปัญหาการหาค่าเหมาะ

วท.บ (วิทยาการข้อมูลและการวิเคราะห์เชิงธุรกิจ) สาขาวิชาวิทยาการข้อมูลและการวิเคราะห์เชิงธุรกิจ คณะเทคโนโลยีสารสนเทศ สจล.
