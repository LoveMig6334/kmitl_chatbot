06066301 โครงสร้างข้อมูลและอัลกอริทึม 3(2-2-5)
DATA STRUCTURES AND ALGORITHMS
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : None
ชนิดของข้อมูล โครงสร้างข้อมูลและชนิดข้อมูลแบบนามธรรม โครงสร้างข้อมูลพื้นฐาน เช่น ลิสต์ สแต็ก และคิว โครงสร้างข้อมูลแบบพลวัต คำศัพท์เฉพาะเกี่ยวกับทรี ไบนารีทรี ไบนารีเสิร์ชทรี เอวิแอลทรี กราฟ การวิเคราะห์โปรแกรมเชิงเวลาและพื้นที่ อัลกอริทึมการเรียงลำดับและการค้นหาข้อมูล อัลกอริทึมแบบละโมบ อัลกอริทึมแบบแบ่งเพื่อเอาชนะ อัลกอริทึมเกี่ยวกับกราฟ และการเขียนโปรแกรมพลวัต

Data types, data structures and abstract data types, basic data structures e.g. list, stack, and queue, dynamic data structures, terminology of trees, binary trees, binary search trees, AVL trees, graph, time and space analysis of programs, sorting and searching algorithms, greedy algorithm, divide and conquer algorithm, graph algorithms, and dynamic programming.
