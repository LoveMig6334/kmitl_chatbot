**06066102 ระบบสารสนเทศเพื่อการจัดการ**
**MANAGEMENT INFORMATION SYSTEMS**
วิชาบังคับก่อน : 06066101 พื้นฐานทางธุรกิจสำหรับเทคโนโลยีสารสนเทศ
PREREQUISITE : 06066101 BUSINESS FUNDAMENTALS FOR INFORMATION TECHNOLOGY

บทบาทของเทคโนโลยีสารสนเทศในธุรกิจ แนวคิดระบบสารสนเทศและการจัดการ การวางแผนเทคโนโลยีสารสนเทศเชิงกลยุทธ์ ความสอดคล้องของเทคโนโลยีสารสนเทศกับกลยุทธ์ ทางธุรกิจ การได้มาซึ่งระบบสารสนเทศ ระบบสารสนเทศตามลักษณะที่สนับสนุนการทำงาน ระบบ สารสนเทศระดับองค์กร แนวโน้มการประยุกต์ใช้เทคโนโลยีสารสนเทศ จริยธรรมและประเด็นทาง สังคม

Roles of information technology in business, information system concepts and management, strategic information technology planning, aligning IT with business strategy, information system acquisition, functional information systems, enterprise systems, trends in applications of information technology, ethical and social issues.

**06066300 แนวคิดระบบฐานข้อมูล**
**DATABASE SYSTEM CONCEPTS**
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : None

แนะนำฐานข้อมูลและระบบจัดการฐานข้อมูล ระบบฐานข้อมูลและสภาพแวดล้อม ระบบจัดการฐานข้อมูล ชนิดของฐานข้อมูล แบบจำลองข้อมูล แบบจำลองฐานข้อมูลเชิงสัมพันธ์ สกี มา อินแสตน รีเลชันชิป กฎบูรณภาพ พจนานุกรมข้อมูล แบบจำลองความสัมพันธ์ระหว่างเอนทิตี ฟังก์ชันดีเพนเดนซี นอร์มัลไลซ์เซชัน พีชคณิตเชิงสัมพันธ์ เอสคิวแอล การประมวลผลทรานแซคชัน แนวคิดคลังข้อมูลและการออกแบบ ปฏิบัติการด้านการจำลองข้อมูลและภาษาฐานข้อมูล

Introduction to the database system and DBMS, database systems and environment, database management systems, types of databases, data models, relational model, schemas, instances, relationships, integrity rules, data dictionary, relational database modeling, entity relationship model, logical design, functional dependencies, normalization, relational algebra, SQL, transaction processing, data warehouse concepts and design, data modeling and database language laboratory.
