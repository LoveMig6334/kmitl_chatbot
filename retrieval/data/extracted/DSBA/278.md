06026254 เทคโนโลยีสุขภาพสนเทศศาสตร์เบื้องต้น 3(2-2-5)
INTRODUCTION TO HEALTH ANALYTICS
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : None
ความรู้เบื้องต้นการวิเคราะห์ข้อมูลด้านสุขภาพ เทคโนโลยีและเครื่องมือทั่วไป
แหล่งข้อมูลด้านการดูแลสุขภาพ มาตรฐานด้านข้อมูลการดูแลสุขภาพ โครงสร้างข้อมูลทางคลินิก
การทำเหมืองข้อมูลด้านสุขภาพ การจำแนกประเภทและการเลือกคุณสมบัติ เทคนิค supervised
และ unsupervised แบบจำลองการคาดการณ์ การวิเคราะห์ข้อมูลสุขภาพเชิงสำรวจ (EDA) และ
เทคนิคการสร้าง visualization ของข้อมูลเชิงวิทยาศาสตร์สุขภาพ ประเภทข้อมูลทางคลินิกของ
ข้อมูลด้านสุขภาพจากแฟ้มบันทึกการดูแลสุขภาพอิเล็กท รอนิกส์และการแลกเปลี่ยนข้อมูลด้าน
สุขภาพ การวิเคราะห์ข้อมูลอนุกรมเวลา

Introduction to Health Data Analysis, Common technologies and tools,
Healthcare Data Sources, Standards in Healthcare Data, Clinical data structure, health
data mining, Classification and Feature Selection, Supervised and Unsupervised
Techniques, Prediction model Exploratory data analysis (EDA) and common
visualization techniques in health care science, Clinical data type of health data in
Electronic Healthcare Record and Healthcare Information Exchange, Time series data
analysis.

CLINICAL DATA ACQUISITION AND MANAGEMENT
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : None
มาตรฐานข้อมูลสุขภาพและโครงสร้าง การวิเคราะห์ข้อมูลวิทยาศาสตร์สุขภาพ การ
เชื่อมต่อของระบบสุขภาพในแง่มุมของผู้ใช้ ประเภทข้อมูลสุขภาพของแฟ้มการดูแลสุขภาพ
อิเล็กทรอนิกส์และการแลกเปลี่ยนข้อมูล การดูแลสุขภาพ ที่มาของแหล่งข้อมูลและการเตรียมข้อมูล
ทางคลินิก เทคนิคการแบ่งส่วนของฟลิ๊มเอ็กซ์เรย์ การเตรียมข้อมูลและแก้ไขข้อมูลภาพทางการ
แพทย์ การเตรียมข้อมูลรูปแบบ คลื่นและอื่นๆ การใช้เทคนิคประมวลภาษาธรรมชาติเชิงการแพทย์

วท.บ (วิทยาการข้อมูลและการวิเคราะห์เชิงธุรกิจ) สาขาวิชาวิทยาการข้อมูลและการวิเคราะห์เชิงธุรกิจ
คณะเทคโนโลยีสารสนเทศ สจล.
