06026206 การวิเคราะห์ข้อมูลและการโปรแกรม 3(2-2-5)
DATA ANALYTICS AND PROGRAMMING
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : None
ในภาคทฤษฎี แนะนำการวิเคราะห์ข้อมูลเชิงธุรกิจและการตัดสินใจ สถิติเชิงพรรณนาการวิเคราะห์ความแปรปรวนหลายตัวแปร การวิเคราะห์ความถดถอยเชิงเส้นอย่างง่าย การวิเคราะห์ความถดถอยเชิงซ้อน การวิเคราะห์จำแนกกลุ่ม(Discriminant Analysis) การวิเคราะห์ความถดถอยโลจิสติก การพยากรณ์และอนุกรมเวลา การหาค่าที่เหมาะสมที่สุด ในภาคปฏิบัติ แนะนำการเขียนโปรแกรมทางสถิติ เช่น ภาษาอาร์ ประเภทข้อมูล ข้อมูลตัวแปรเดี่ยว ข้อมูลตัวแปรคู่ ข้อมูลหลายตัวแปร สถิติเชิงพรรณา ตัวแปรอาร์เรย์ เมตริกซ์ ข้อมูลรายการและเฟรมข้อมูล โครงสร้างการควบคุม การวนลูป การพล็อตกราฟและกราฟฟิค การจัดการข้อมูล การสร้างฟังก์ชัน และแพคเกจ รวมทั้งการใช้โปรแกรมสำเร็จรูปทางสถิติในการวิเคราะห์ข้อมูล

Introduction to business data analytics and decision making, descriptive statistics, multivariate analysis of variance, simple regression analysis, multiple regression analysis, discriminant analysis , logistic regression analysis, forecasting and time series, optimization, overview of statistical programming, e.g., R programming, numerical arithmetic, data type, univariate data, bivariate data, multivariate data, descriptive statistics, arrays and matrices, lists and dataframes, control structures, loop functions, plotting and graphics, data management, function and package development, statistical package software for data analysis.

06026207 ระบบฐานข้อมูลแบบโนเอสคิวแอล 3(2-2-5)
NOSQL DATABASE SYSTEMS
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : None
แนะนำระบบฐานข้อมูลแบบไม่ใช่เชิงสัมพันธ์ ความแตกต่างจากระบบฐานข้อมูลเชิงสัมพันธ์ ข้อดีและข้อเสียของฐานข้อมูลแบบไม่ใช่เชิงสัมพันธ์ ชนิดและโครงสร้างฐานข้อมูลแบบไม่ใช่เชิงสัมพันธ์ แบบคอลัมน์ แบบคีย์เวลยู แบบเอกสาร และแบบกราฟ ตัวอย่างการออกแบบฐานข้อมูลแบบไม่ใช่เชิงสัมพันธ์ การใช้ภาษาเจสันกับฐานข้อมูลแบบไม่ใช่เชิงสัมพันธ์ แนะนำภาษาเจสันไวยากรณ์ของเจสัน ชนิดข้อมูลของเจสัน

Introduction to NoSQL database system, differences between NoSQL database system and relational database system, advantages and disadvantages of NoSQL database system, types of NoSQL database system: column-oriented key-value, document and graph, example of NoSQL database design, JSON &amp; NoSQL database, introduction to JavaScript Object Notation (JSON), JSON syntax, JSON data types.
