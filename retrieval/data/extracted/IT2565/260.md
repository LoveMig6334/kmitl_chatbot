06016430 การพัฒนาคลาวด์แอปพลิเคชัน
3(2-2-5)
CLOUD APPLICATION DEVELOPMENT
วิชาบังคับก่อน : 06016404 เทคโนโลยีกลุ่มเมฆ
PREREQUISITE : 06016404 CLOUD COMPUTING
ความรู้เบื้องต้นของเทคโนโลยีคลาวด์ สถาปัตยกรรมคลาวด์ คุณลักษณะการสร้างเครื่องจำลอง และการให้บริการผู้ใช้หลายคนพร้อมกัน หลักการพัฒนาแอปพลิเคชันสำหรับองค์กรในคลาวด์ การ พัฒนาแอปพลิเคชันโดยวิธีการประกาศและวิธีระบุปัญหา ข้อจำกัดของการกำกับดูแล ประเด็นที่พบ บ่อยระหว่างการพัฒนาคลาวด์แอปพลิเคชันแบบคลาวด์ ปัจจัยด้านความต้องการหรือความสามารถใน การเลือกรูปแบบการพัฒนาที่เหมาะสม การวิเคราะห์ข้อมูลโดยใช้แพลตฟอร์มแบบคลาวด์ หลักการ จัดการฐานข้อมูลคลาวด์ โนเอสคิวแอล
Introduction to Cloud Technology, Cloud Architecture, Virtualization and Multi- Tenancy Features, Principles to Develop Enterprise Application in Cloud, Declarative and Problematic Application Development, Governance Limits, Requirement or Capability Factors towards the Selection of Appropriate Development Paradigms, principle to cloud database management, NoSQL.

วท.บ.(เทคโนโลยีสารสนเทศ) สาขาวิชาเทคโนโลยีสารสนเทศ คณะเทคโนโลยีสารสนเทศ สจล.
