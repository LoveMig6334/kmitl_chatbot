06016425 พื้นฐานการออกแบบทัศนศิลป์สำหรับสื่อปฏิสัมพันธ์
3(2-2-5)
VISUAL DESIGN FUNDAMENTALS FOR INTERACTIVE MEDIA
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : NONE
องค์ประกอบของการออกแบบทัศนศิลป์ หลักการออกแบบทัศนศิลป์ ลำดับชั้นขององค์ประกอบเชิงทัศน์ การจัดวางองค์ประกอบ แบบอักษรและการเลือกใช้ ข้อแนะนำในการใช้สี การออกแบบและใช้งานไอคอน พื้นฐานการนำเสนอข้อมูลด้วยภาพ กระบวนการออกแบบทัศนศิลป์ การประยุกต์ใช้การออกแบบทัศนศิลป์สำหรับเว็บและสื่อปฏิสัมพันธ์ เครื่องมือและแหล่งทรัพยากรสำหรับการออกแบบทัศนศิลป์
Elements of visual design, principles of visual design, visual hierarchy, layout composition, typefaces and usages, color usage guidelines, icon design and usage, data visualization basics, visual design process, application of visual design in web and interactive media, visual design tools and resources.

06016426 คอมพิวเตอร์กราฟิกส์และแอนิเมชัน
3(2-2-5)
COMPUTER GRAPHICS AND ANIMATION
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : NONE
กราฟิกแบบราสเตอร์และแบบเวเกเตอร์ การจัดเก็บข้อมูลรูปทรงวัตถุแบบสองและสามมิติ เทคนิคการฉายภาพและการแปลง เทคนิคด้านแสงและแสงเงาสามมิติ เทคนิคการสร้างลวดลายของพื้นผิวสามมิติ เทคนิคการเรนเดอร์ภาพสามมิติ แนวคิดพื้นฐานการสร้างภาพเคลื่อนไหวด้วยคอมพิวเตอร์ แบบสามมิติ การใช้งานซอฟต์แวร์สร้างภาพกราฟิกสามมิติและการสร้างภาพเคลื่อนไหวสามมิติเบื้องต้น
Raster and vector graphics, 2D and 3D object representations, 3D projection and transformation techniques, 3D lighting and shading techniques, 3D texture mapping techniques, 3D rendering techniques, basic 3D computer animation concepts, use of 3D computer graphics application software for basic 3D modeling and animation.

วท.บ.(เทคโนโลยีสารสนเทศ) สาขาวิชาเทคโนโลยีสารสนเทศ คณะเทคโนโลยีสารสนเทศ สจล.
