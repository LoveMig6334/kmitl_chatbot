06016403 เทคโนโลยีสื่อประสม 3(2-2-5)
MULTIMEDIA TECHNOLOGY
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : NONE
ประเภทของสื่อดิจิทัลการเก็บข้อมูลมัลติมีเดีย การบีบอัดข้อมูลมัลติมีเดีย การส่งเนื้อหา มัลติมีเดีย รูปแบบไฟล์มัลติมีเดีย การประมวลผลข้อมูลมัลติมีเดียอุปกรณ์อินพุตเอาต์พุตมัลติมีเดีย เซ็นเซอร์อุปกรณ์เคลื่อนที่ เทคโนโลยีเซิร์ฟเวอร์สื่อ เช่น การสตรีมวิดีโอ VoD, CDN และ CMS เซิร์ฟเวอร์ เทคโนโลยีมัลติมีเดียขั้นสูงและแอปพลิเคชั่น เช่น วิดีโอ 360 องศา ภาพ HDR เทคโนโลยี VR AR/MR เครื่องมือสำหรับสร้างเนื้อหามัลติมีเดียเชิงโต้ตอบ
Types of digital media, multimedia data acquisition, multimedia data compression, delivery of multimedia content, multimedia file formats, multimedia data processing, multimedia i/o devices including mobile device sensors, media server technologies such as video streaming, VoD, CDN, and CMS servers, advanced multimedia technologies such as 360-degree video, HDR imaging, VR, AR/MR technologies and their applications, tools for creating multimedia and interactive content.

06016404 เทคโนโลยีกลุ่มเมฆ 3(2-2-5)
CLOUD COMPUTING
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : NONE
หลักการพื้นฐานของระบบคลาวด์รูปแบบการให้บริการของระบบคลาวด์องค์ประกอบบริการ พื้นฐานของระบบคลาวด์ ยกตัวอย่าง เช่น ตัวประมวลผล ตัวจัดเก็บข้อมูล ระบบเครือข่ายและฐานข้อมูล ประโยชน์ที่ได้จากการติดตั้งระบบบนคลาวด์รูปแบบต่าง ๆ ของการออกแบบโครงสร้างระบบบนคลาวด์ ขึ้นพื้นฐาน ระบบความปลอดภัยบนคลาวด์เบื้องต้น รูปแบบการคิดค่าบริการของบริการของระบบ คลาวด์
Cloud-computing concept, Cloud delivery models, Cloud foundation services, such as compute, storage, network and database, Benefits of cloud adoption, Overview of multiple cloud architecture design principle, Overview of cloud security concepts, Billing and pricing in public cloud services
