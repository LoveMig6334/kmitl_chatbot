06016440 การออกแบบเครือข่ายสารสนเทศ
3(3-0-6)
INFORMATION NETWORK DESIGN
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : NONE
การออกแบบเครือข่ายสารสนเทศเบื้องต้น ขั้นตอนการออกแบบ การกำหนดความต้องการใน การออกแบบ พารามิเตอร์ในการออกแบบเครือข่าย การเลือกรูปแบบและสถาปัตยกรรม การคำนวณใน การออกแบบ การออกแบบเส้นทางและตำแหน่งที่อยู่ การออกแบบความมั่นคงปลอดภัย การเลือกสื่อ ตัวกลางและองค์ประกอบต่างๆ ข้อกำหนดและมาตรฐาน การประเมินประสิทธิภาพ การทดสอบและ ตรวจสอบความถูกต้องของการออกแบบ การวางแผนและจัดทำเอกสาร

Introduction to information network design, design process, design requirement, networking design parameters, topology and architecture selection, design calculation, addressing and routing design, security design, media and components selection, specification and standards, performance evaluation, testing and validation, planning and document

06016441 ประสิทธิภาพเครือข่ายและระบบ
3(3-0-6)
NETWORK AND SYSTEM PERFORMANCE
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : NONE
เครื่องมือและเทคโนโลยีสำหรับการประเมินและปรับปรุงประสิทธิภาพเครือข่ายและระบบ การวัดประสิทธิภาพ การสร้างแบบจำลองและการวิเคราะห์ประสิทธิภาพเครือข่ายและระบบในด้าน ต่าง ๆ เช่น ความน่าเชื่อถือ การสูญเสียแพ็คเก็ต ทรูพุท ดีเลย์ การรองรับการเพิ่มภาระงาน ความ พร้อมใช้และความมั่นคงปลอดภัย ปัจจัยที่มีผลกระทบต่อประสิทธิภาพ การวิเคราะห์ด้วยแบบจำลองท ราฟฟิก ห่วงโซ่มาร์คอฟและทฤษฎีคิว ตัวอย่างโซลูชันจริง เช่น สถาปัตยกรรมเครือข่ายทนทาน กลไก ควบคุมทราฟฟิกและรับประกันคุณภาพ

Tools and technologies for evaluating and improving the performance of networks and systems, measurement, modeling, and analysis of network and system performance including reliability, packet loss, throughput, delay, scalability, availability, and security, factors affecting network and system performance, quantitative methods for performance analysis, using techniques from traffic modeling, Markov chains, and queueing theory, examples of practical solutions: resilient network and system architecture, traffic control, and QoS mechanism.

วท.บ.(เทคโนโลยีสารสนเทศ) สาขาวิชาเทคโนโลยีสารสนเทศ คณะเทคโนโลยีสารสนเทศ สจล.
