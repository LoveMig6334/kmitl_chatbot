06016463 เทคโนโลยีการคำนวณด้วยคอมพิวเตอร์แบบผสมผสาน
HYBRID COMPUTING TECHNOLOGY
3(3-0-6)
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : NONE

พื้นฐานของการคำนวณด้วยคอมพิวเตอร์ วิวัฒนาการของการคำนวณด้วยคอมพิวเตอร์ ประเภทของเทคโนโลยีการคำนวณด้วยคอมพิวเตอร์ ได้แก่ การคำนวณด้วยหน่วยประมวลผลกลาง (CPU) การคำนวณด้วยหน่วยประมวลผลกราฟฟิก (GPU) การคำนวณด้วยหน่วยประมวลผลเทเนเซอร์ (TPU) และการคำนวณด้วยวงจรดิจิตอลที่โปรแกรมได้ (FPGA) หลักการทำงานของหน่วยประมวลผลกลาง หน่วยประมวลผลกราฟฟิก หน่วยประมวลผลเทเนเซอร์ และวงจรดิจิตอลที่โปรแกรมได้ การพัฒนาซอฟต์แวร์สำหรับการคำนวณด้วยหน่วยประมวลผลแบบต่าง ๆ ภาษาการโปรแกรมสำหรับการคำนวณด้วยคอมพิวเตอร์แบบผสมผสาน ได้แก่ CUDA และ OpenCL การเปรียบเทียบการคำนวณแบบต่าง ๆ ทั้งข้อดี-ข้อเสีย รวมถึงพลังงานที่ใช้และประสิทธิภาพการคำนวณด้วยคอมพิวเตอร์ของเทคโนโลยีแบบต่าง ๆ การประยุกต์ใช้งานการคำนวณด้วยคอมพิวเตอร์แบบผสมผสาน เช่น การประยุกต์ใช้ในงานด้านปัญญาประดิษฐ์ การคำนวณด้วยคอมพิวเตอร์ประสิทธิภาพสูง (HPC) และอื่น ๆ

Fundamental of computer processing and computation, Evolution of computing technology, computing technology of CPU (Central Processing Unit), GPU (Graphics Processing Unit), TPU (Tensor Processing Unit) and FPGA (Field Programmable Gate Array), Software development for hybrid computing, hybrid computing programming architecture and languages, such as CUDA and OpenCL, Computing technology comparisons including advantages and disadvantages, performance and power consumption, Hybrid computing applications, such as artificial intelligence, high performance computing and others.

06016464 ความมั่นคงปลอดภัยไซเบอร์ทางปฏิบัติ
PRACTICAL CYBER SECURITY
3(2-2-5)
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : NONE

การเรียนรู้ภาคทฤษฎีและภาคปฏิบัติในความมั่นคงปลอดภัยไซเบอร์ ความมั่นคงปลอดภัยเครือข่ายเบื้องต้น ปัญหาพื้นฐานของความมั่นคงปลอดภัย การป้องกันความปลอดภัยในการสื่อสาร การทำงานของชั้นความปลอดภัย การรับรองความมั่นคงปลอดภัย ลายเซ็นดิจิทัล โพรโตคลการใช้งานที่ปลอดภัยเบื้องต้น การรักษาความมั่นคงปลอดภัยในบริการจดหมายอิเล็กทรอนิกส์ การรักษาความมั่นคงปลอดภัยในจดหมายอิเล็กทรอนิกส์ปลายทาง ความมั่นคงปลอดภัยของเว็บ ความมั่นคง

วท.บ.(เทคโนโลยีสารสนเทศ) สาขาวิชาเทคโนโลยีสารสนเทศ คณะเทคโนโลยีสารสนเทศ สจล.
