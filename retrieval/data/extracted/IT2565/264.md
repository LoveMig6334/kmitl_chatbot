06016438 ความปลอดภัยสำหรับระบบคลาวด์ 3(3-0-6)
CLOUD SECURITY
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : NONE
สิ่งที่ต้องพิจารณาเกี่ยวกับความปลอดภัยของระบบคลาวด์ ความปลอดภัยของโครงสร้าง พื้นฐานของระบบคลาวด์ ความปลอดภัยของตัวข้อมูลและตัวจัดเก็บข้อมูลบนระบบคลาวด์ การจัดการ นโยบายทางด้านความปลอดภัยและการติดตามและบันทึกเหตุการณ์ทางความปลอดภัยที่เกิดขึ้น
Cloud security considerations, Cloud infrastructure security, Cloud data and storage security, Security policy implementation, Monitoring and logging security incidents

06016439 เทคโนโลยีเครือข่ายไร้สาย 3(3-0-6)
WIRELESS NETWORK TECHNOLOGY
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : NONE
ความรู้เบื้องต้นเกี่ยวกับเทคโนโลยีและแอปพลิเคชันเครือข่ายไร้สาย พื้นฐานการส่งผ่านแบบไร้ สาย การแพร่กระจายคลื่นวิทยุ สายอากาศ การมอดดูเลต การมัลติเพล็กซ์ การควบคุมการเข้าถึงพร้อม กันแบบหลายทาง เครือข่ายท้องถิ่นไร้สาย มาตรฐาน IEEE 802.11 การสำรวจสถานที่ การวางแผน การออกแบบ และการปรับใช้เครือข่ายท้องถิ่นไร้สาย ความปลอดภัยบนเครือข่ายท้องถิ่นไร้สายและ มาตรฐานที่เกี่ยวข้อง เครือข่ายส่วนบุคคลไร้สาย เครือข่ายเมืองไร้สาย เครือข่ายพื้นที่กว้างไร้สาย พื้นฐานการจัดการและการแก้ปัญหาเครือข่ายไร้สาย
Introduction to wireless network technologies and applications, wireless transmission basics, radio propagation, antennas, modulation, multiplexing, multiple access control, wireless local area network ( WLAN), IEEE 802.11 standards, site survey, planning, design, and deploying WLAN, WLAN security and related standards, wireless personal area network (WPAN), wireless metropolitan area network (WMAN), wireless wide area network (WWAN), wireless network management and troubleshooting basics.

วท.บ.(เทคโนโลยีสารสนเทศ) สาขาวิชาเทคโนโลยีสารสนเทศ คณะเทคโนโลยีสารสนเทศ สจล.
