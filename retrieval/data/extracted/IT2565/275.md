06016461 การประมวลผลภาษาธรรมชาติเบื้องต้น
INTRODUCTION TO NATURAL LANGUAGE PROCESSING
3(3-0-6)
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : NONE
ภาพรวมโมดูลการประมวลผลภาษาธรรมชาติ งานด้านการแบ่งกลุ่มข้อความ เช่น การจัดกลุ่ม ข่าว การจำแนกอารมณ์ การกรองสแปม ตัวแบ่งกลุ่มแบบดั้งเดิม เทคนิคการเรียนรู้เชิงลึก แบบจำลอง ภาษาและการกำกับข้อความที่มีลำดับ การแทนข้อความในแบบจำลองเวคเตอร์ งานด้านการสร้างแบบ รูปของงานที่มีลำดับ เช่น การแปลภาษาด้วยเครื่อง การย่อความ การตอบคำถาม
Overview of natural language processing module, text classification tasks such as news classification, sentiment analysis, spam filtering, traditional classifiers, deep learning techniques, language modeling and sequence tagging, text representation in vector space models, formulate sequence to sequence tasks such as machine translation, summarization, question answering

06016462 เทคโนโลยีสื่อสารเคลื่อนที่
MOBILE COMMUNICATION TECHNOLOGY
3(3-0-6)
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : NONE
ภาพรวมของเครือข่ายและระบบสื่อสารเคลื่อนที่ พื้นฐานการสื่อสารเคลื่อนที่ สถาปัตยกรรม และองค์ประกอบของระบบโทรศัพท์เคลื่อนที่ เทคโนโลยีระบบโทรศัพท์เคลื่อนที่จีเอสเอ็ม ทีดีเอ็มเอ ซีดีเอ็มเอ แอลทีอี และเทคโนโลยีในอนาคต บริการข้อมูลและแอปพลิเคชันในระบบโทรศัพท์เคลื่อนที่ พื้นฐานความปลอดภัยในระบบสื่อสารเคลื่อนที่
An overview of mobile communication systems and networks, mobile communications basics, mobile phone system components and architectures, mobile phone system technologies GSM, TDMA, CDMA, LTE, and future technologies, data services and applications in mobile phone systems, basic security in mobile communication systems.
