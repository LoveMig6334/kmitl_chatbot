06016424 การออกแบบส่วนต่อประสานกับมนุษย์ 3(3-0-6)
HUMAN INTERFACE DESIGN
วิชาบังคับก่อน : ไม่มี
PREREQUISITE : NONE
หลักการออกแบบโดยมีผู้ใช้เป็นศูนย์กลาง กระบวนการออกแบบส่วนต่อประสานกับผู้ใช้และประสบการณ์สำหรับผู้ใช้ การวิเคราะห์ผู้ใช้และการวิเคราะห์งาน ความต้องการด้านการใช้ประโยชน์ได้ ปัจจัยที่เกี่ยวกับมนุษย์และหลักการทางจิตวิทยาสำหรับการออกแบบส่วนต่อประสานกับผู้ใช้ แบบจำลองการปฏิสัมพันธ์ รูปแบบของการปฏิสัมพันธ์ หลักการและข้อแนะนำในการออกแบบ เทคนิค การประเมินผล ข้อแนะนำพื้นฐานในการออกแบบสำหรับเว็บและแอพลิเคชันบนอุปกรณ์แบบพกพาได้ เครื่องมือในการสร้างต้นแบบ เทคโนโลยีอินพุทและเอาท์พุทสำหรับการปฏิสัมพันธ์กับมนุษย์
Principles of user-centered design, user interface and user experience design process, user and task analysis, usability requirements, human factors and psychological principles for user interface design, interaction models, interaction styles, design principles and guidelines, evaluation techniques, basic design guidelines for web and mobile applications, prototyping tools, I/O technologies for human computer interaction.
